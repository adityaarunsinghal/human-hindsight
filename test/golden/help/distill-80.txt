human-hindsight distill
Build a prompt library from your exported sessions.

Examples
  human-hindsight distill --dry-run
    Preview the plan before sending any session text.

  human-hindsight distill --recent 10
    Start with your ten most recent eligible sessions.

  human-hindsight distill --quality best
    Review the plan using the most capable available models.

Common options
  --dry-run                Print the plan and exit; nothing is sent
  --recent 25              Start with this many of your most recent sessions
  --quality balanced|best  Model plan for reading and writing (default:
                           balanced)
  --project <name>         Only distill sessions from this project

human-hindsight copy
Copy a prompt to paste into a new coding session.

Examples
  human-hindsight copy review-changes
    Copy the prompt body. Use a name from list.

  human-hindsight copy review-changes --no-follow-up
    Copy the prompt and return to the shell.

Common options
  --home <dir>  Data directory (env HUMAN_HINDSIGHT_HOME; legacy
                CC_HINDSIGHT_HOME is also supported)
  --follow-up   Offer next steps in a terminal (disable with --no-follow-up)

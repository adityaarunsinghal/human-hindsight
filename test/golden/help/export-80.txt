human-hindsight export
Save your messages from coding sessions as Markdown.

Examples
  human-hindsight export
    Export your messages from all available histories on this machine.

  human-hindsight export --project my-app
    Export one project. Use its name from scan.

Common options
  --project <name>    Only export sessions from this project
  --source <tool>     History to read: claude, codex, kiro, kirocrew, opencode,
                      or auto (default)
  --min-messages <n>  Minimum human messages for a session to be exported

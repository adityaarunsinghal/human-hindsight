npx human-hindsight status
See what has finished and what to run next.

Examples
  npx human-hindsight status
    See how many sessions have become library prompts.

  npx human-hindsight status --home ./hindsight-data
    Check a library in a different data directory.

Common options
  --home <dir>  Data directory (env HUMAN_HINDSIGHT_HOME; legacy
                CC_HINDSIGHT_HOME is also supported)
  --follow-up   Offer next steps in a terminal (disable with --no-follow-up)

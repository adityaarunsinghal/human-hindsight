npx human-hindsight doctor
Check your history, installed tools, and sign-in hints.

Examples
  npx human-hindsight doctor
    See which tools are installed and how to fix setup problems.

  npx human-hindsight doctor --home ./hindsight-data
    Check the data directory you plan to use.

Common options
  --home <dir>  Data directory (env HUMAN_HINDSIGHT_HOME; legacy
                CC_HINDSIGHT_HOME is also supported)

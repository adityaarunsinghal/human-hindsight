Human Hindsight 2.1.2
Understand how you work. Codify your taste.

Global options
Usage
  npx human-hindsight [OPTIONS]

Options

  --quality fast|balanced|best  Model plan and reasoning effort: fast (low),
                                balanced (high, the default), or best (extra
                                high)
  --recent 25                   Start with this many of your most recent
                                sessions
  --plain                       Use numbered prompts and static progress (env
                                HUMAN_HINDSIGHT_PLAIN=1)
  --follow-up                   Offer next steps in a terminal (disable with
                                --no-follow-up)
  --runner <cli>                Coding CLI for model calls: claude, codex, kiro,
                                opencode, or auto (default)
  --model <name>                Model for every reflection step, in place of the
                                --quality plan
  --cluster-model <name>        Model for grouping sessions into tasks only
                                (default: --model)
  --author-model <name>         Model for writing prompts only (default:
                                --model)
  --project <name>              Only projects whose name contains this text,
                                kept through every step
  --home <dir>                  Data directory (env HUMAN_HINDSIGHT_HOME; legacy
                                CC_HINDSIGHT_HOME is also supported)
  --claude-dir <dir>            Claude Code config directory (env
                                CLAUDE_CONFIG_DIR; default ~/.claude)
  --codex-dir <dir>             Codex data directory (env CODEX_HOME; default
                                ~/.codex)
  --kiro-dir <dir>              Kiro CLI config directory (env KIRO_CONFIG_DIR;
                                default ~/.kiro)
  --kirocrew-dir <dir>          Kiro Crew data directory (env
                                HUMAN_HINDSIGHT_KIROCREW_DIR; default
                                ~/.kiro/crew)
  --opencode-dir <dir>          OpenCode data directory (env
                                HUMAN_HINDSIGHT_OPENCODE_DIR; honors
                                XDG_DATA_HOME)
  --opencode-db <file>          OpenCode database (env OPENCODE_DB; relative to
                                --opencode-dir)
  --source <tool>               History to read: claude, codex, kiro, kirocrew,
                                opencode, or auto (default)
  -h, --help                    Show examples and common options
  --all                         Show the full reference when requesting help
  -v, --version                 Print the installed version

npx human-hindsight reflect
Find preferences and reusable prompts in your sessions.
The earlier name distill still works.
Usage
  npx human-hindsight reflect [OPTIONS]

Options

  --runner <cli>                           Which local CLI runs the reflection:
                                           claude, codex, kiro, opencode, or
                                           auto (default). One name keeps the
                                           run on that CLI; several, separated
                                           by commas, are tried in order
  --model <name>                           Model for every step, as your CLI
                                           names it
  --cluster-model <name>                   Model for grouping sessions only
                                           (defaults to --model)
  --author-model <name>                    Model for writing prompts only
                                           (defaults to --model)
  --project <name>                         Only reflect on sessions from this
                                           project
  --group                                  Group sessions into tasks (use
                                           --no-group for one prompt per
                                           session)
  --breaker                                Stop a parallel stage after 5
                                           consecutive identical failures (use
                                           --no-breaker to attempt every
                                           session) (Default: true)
  --no-breaker                             Turn off --breaker
  --library                                Serve the local library during an
                                           interactive reflection (skip with
                                           --no-library)
  --prompts                                Group sessions and write reusable
                                           prompts (use --no-prompts to read
                                           sessions and summarize preferences
                                           only) (Default: true)
  --no-prompts                             Turn off --prompts
  --subagents                              After the preference summaries,
                                           suggest subagent roles in the same
                                           run, on the same approval
  --generalize                             Summarize working preferences after
                                           writing prompts (skip with
                                           --no-generalize) (Default: true)
  --no-generalize                          Turn off --generalize
  --min-substance <n>                      Minimum human messages for a session
                                           to be eligible
  --cluster-batch-size <n>                 Maximum sessions per grouping call
                                           (positive integer; not with
                                           --retry-failed)
  --fresh                                  Discard saved session reads and
                                           grouping, then rebuild
  --dry-run                                Print the plan and exit; nothing is
                                           sent
  --yes                                    Approve the plan without asking (for
                                           scripting)
  --input-budget <characters>              Max characters of session content per
                                           call (default 400000)
  --truncate never|extreme                 Sessions over the size limit per
                                           call: never (default, skip and
                                           report) or extreme (shorten to fit)
  --timeout <seconds>                      Per-call timeout in seconds (default
                                           900; calls over many sessions scale)
  --concurrency <n>                        Session reads, prompt writes, and
                                           preference summaries run in parallel
                                           (default 10)
  --force                                  Rewrite prompts you edited by hand
                                           (default: keep your edits)
  --retry-failed                           Retry only the calls that failed;
                                           keep the saved grouping and every
                                           finished result
  --retry-stage all|digest|cluster|author  Retry one step only: digest (reading
                                           sessions), cluster (grouping), author
                                           (writing), or all (default)
  --recover-tasks <names>                  Explicitly recover named saved tasks
                                           from older runs (comma-separated
                                           names)
  --verbose                                Show which sessions and prompts are
                                           being worked on, and per-item detail

npx human-hindsight preferences
Print accepted working preferences for your instruction file.
Usage
  npx human-hindsight preferences [OPTIONS]

Options

  --runner <cli>        Which local CLI consolidates: claude, codex, kiro,
                        opencode, or auto (default). One name keeps the run on
                        that CLI; several, separated by commas, are tried in
                        order
  --model <name>        Model for --consolidate, passed to the CLI's --model
  --project <name>      Include accepted instructions for this exact project,
                        alongside global instructions
  --include-unreviewed  Explicitly include unreviewed suggestions instead of
                        only accepted instructions
  --target <tool>       Output target: claude (CLAUDE.md), codex/opencode/agents
                        (AGENTS.md), or kiro/kirocrew (steering file, also
                        loaded by Kiro Crew). Default: inferred from --source
  --consolidate         Merge near-duplicates with one model call through your
                        CLI and save in the library (asks first)
  --timeout <seconds>   Consolidation call timeout in seconds (default scales
                        with the preference count)
  --yes                 Approve the plan without asking (for scripting)

npx human-hindsight suggest-subagents
Generate specialist subagents from your working preferences.
Usage
  npx human-hindsight suggest-subagents [OPTIONS]

Options

  --runner <cli>               Which local CLI runs the stages: claude, codex,
                               kiro, opencode, or auto (default). One name keeps
                               the run on that CLI; several, separated by
                               commas, are tried in order
  --model <name>               Model for summarizing preferences (env
                               HUMAN_HINDSIGHT_SUBAGENT_MODEL; default: the
                               selected plan)
  --author-model <name>        Model for writing role prompts (default: --model,
                               else the selected plan)
  --propose-model <name>       Model for choosing roles (default: --model, else
                               the selected plan)
  --include-unreviewed         Use every preference you have not dismissed, even
                               when some are accepted
  --min-roles <n>              Fewest roles to propose (2 to 15, default 2)
  --max-roles <n>              Most roles to propose (2 to 15, default 15)
  --concurrency <n>            Most preference batches or role prompts at a time
                               (default 10)
  --input-budget <characters>  Size limit per call, in characters of preferences
                               (default 400000)
  --window-size <n>            Most preferences per summary call (default 100)
  --fresh-generalize           Summarize every preference again, replacing the
                               saved preference summaries
  --author-only                Finish unwritten role prompts in the interrupted
                               or saved suggestion
  --timeout <seconds>          Time limit per call in seconds (default 900, plus
                               5 per preference)
  --dry-run                    Print the call plan and the inputs; run nothing
  --yes                        Approve the plan without asking (for scripting)
  --verbose                    Show which batches and roles are being worked on
  --export <dir>               Write the saved suggestion as files under this
                               directory (no model calls)
  --target <tool>              With --export: claude, codex, kiro, kirocrew,
                               knowledge, or all (default: all)
  --force                      With --export: overwrite files that already exist
  --pin-model <name>           With --export: write this model id into the
                               Claude Code, Kiro CLI and Kiro Crew files
                               (default: inherit)

  npx human-hindsight gui [OPTIONS]

Options

  --port <number>                      Local port (4317 over SSH, otherwise
                                       automatic)
  --tab prompts|preferences|subagents  Open the prompts, preferences, or
                                       subagents overview
  --open                               Open your browser (use --no-open to print
                                       the address only) (Default: true)

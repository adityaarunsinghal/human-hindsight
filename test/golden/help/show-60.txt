npx human-hindsight show
Read a saved prompt in your terminal.

Examples
  npx human-hindsight show review-changes
    Replace review-changes with a name from list.

  npx human-hindsight show review-changes --raw
    Print the prompt body as Markdown.

Common options
  --raw        Print the prompt as plain Markdown, without
               styling or wrapping
  --follow-up  Offer next steps in a terminal (disable with
               --no-follow-up)

More help
  npx human-hindsight show --help --all
    Every option for this command
  npx human-hindsight doctor
    Check your setup
  npx human-hindsight help --all
    All commands and options
